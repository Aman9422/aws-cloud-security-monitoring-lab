## Evidence handling

Only sanitized evidence should be published. Account IDs, personal email addresses, access keys, secret keys, passwords, session tokens, and unnecessary sensitive log details are excluded from public project materials. The testing report distinguishes observed results from configuration-only or manually triggered tests.
